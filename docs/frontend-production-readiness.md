## Implemented hardening

- Darkened secondary text from `#64748B` to `#59697F`: browser axe measured 4.42:1 for the old color against `#F4F7FB`, below 4.5:1. Preserved sidebar/action/status palette.
- Named and made the dashboard's exact-value table scroll region keyboard-focusable.
- Preserved payment/expense column headers in mobile accessibility trees with visual clipping instead of `display:none`.
- Lazy-loaded login/register/session pages and added the public-route hydration fallback to preserve session-loading feedback and eliminate the observed router warning.
- Added a router-completion test helper for cold lazy-route startup instead of racing module imports against a DOM polling timeout. Financial assertions remain intact; component timeouts, worker count, retry policies and financial rules were not loosened.
- Kept cold Vitest dependency transforms in suite setup for the four affected financial suites; real cold lazy chunks remain covered by compiled browser tests. The helper does not hold a global async React `act()` scope across imports, preventing a timed-out import from poisoning later rendering. Customer-choice checks use the specific select's accessibility tree rather than repeatedly scanning the entire invoice editor.
- Added separate Edge/axe simulated, guarded live and production-preview test configurations. Outputs and browser binaries are excluded from Git. Live network traces are disabled.
- Added reproducible initial-JavaScript measurement that follows static imports instead of counting only the entry file.
